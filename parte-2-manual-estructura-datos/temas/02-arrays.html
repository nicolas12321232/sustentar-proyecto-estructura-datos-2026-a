Tema 2

Arrays y Tipos de Datos

Comprende cómo funcionan los arreglos y los diferentes tipos de datos utilizados para almacenar información dentro de un programa.

Comenzar

Pantalla de Documentación

Definición

Un array es una estructura de datos lineal que permite almacenar múltiples elementos del mismo tipo en posiciones consecutivas de memoria.

Utilidad

Facilitan el almacenamiento y acceso rápido a grandes cantidades de información utilizando índices numéricos.

Características

  • Tamaño definido
  • Acceso mediante índices
  • Datos homogéneos
  • Almacenamiento contiguo
  • Recorrido secuencial

Representación

Los arrays se representan mediante posiciones indexadas que inician generalmente desde el índice 0. 


int numeros[5] = {10,20,30,40,50};

Tipos de Datos y Casos de Uso

  • int → números enteros
  • float → números decimales
  • char → caracteres
  • bool → valores verdaderos o falsos
  • string → cadenas de texto

Se utilizan en registros estudiantiles, inventarios, videojuegos, sistemas bancarios y aplicaciones web.
