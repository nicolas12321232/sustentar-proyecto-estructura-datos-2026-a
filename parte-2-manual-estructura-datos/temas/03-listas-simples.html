Tema 3

Listas Enlazadas Simples

Aprende cómo funcionan las estructuras dinámicas basadas en nodos conectados mediante referencias o punteros.

Comenzar

Pantalla de Documentación

Definición

Una lista enlazada simple es una estructura de datos formada por nodos conectados entre sí mediante enlaces. Cada nodo almacena un dato y una referencia al siguiente nodo.

Utilidad

Permiten almacenar información de forma dinámica, facilitando inserciones y eliminaciones sin necesidad de reorganizar toda la estructura.

Características

  • Estructura dinámica
  • Uso de nodos
  • Acceso secuencial
  • Uso eficiente de memoria
  • Inserciones rápidas

Representación

Cada nodo contiene un dato y un enlace hacia el siguiente elemento. 


[10 | * ] → [20 | * ] → [30 | NULL]

El último nodo apunta a NULL indicando el final de la lista.

Casos de Uso

  • Gestión dinámica de memoria
  • Historiales de navegación
  • Implementación de pilas y colas
  • Sistemas de reproducción multimedia
  • Procesamiento de datos secuenciales

Pantalla de Ejemplos

Paso 1

Crear la estructura del nodo. 


struct Nodo{
   int dato;
   Nodo *siguiente;
};
Paso 2

Crear nodos dinámicamente. 


Nodo *primero = new Nodo();
Nodo *segundo = new Nodo();
Paso 3

Enlazar los nodos utilizando el puntero siguiente. 


primero->siguiente = segundo;

Paso 1

Crear un puntero auxiliar. 


Nodo *aux = primero;
Paso 2

Utilizar un ciclo while para recorrer los nodos. 


while(aux != NULL){
   cout << aux->dato;
   aux = aux->siguiente;
}
Paso 3

El recorrido finalizará cuando el puntero llegue a NULL.
