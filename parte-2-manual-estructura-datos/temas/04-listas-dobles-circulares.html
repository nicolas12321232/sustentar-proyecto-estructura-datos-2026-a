Tema 4

Listas Enlazadas Dobles y Circulares

Comprende cómo funcionan las listas con enlaces bidireccionales y estructuras circulares utilizadas en sistemas dinámicos.

Comenzar

Pantalla de Documentación

Definición

Las listas dobles poseen nodos conectados hacia adelante y hacia atrás. Las listas circulares conectan el último nodo nuevamente con el primero formando un ciclo continuo.

Utilidad

Permiten recorridos bidireccionales y navegación continua, mejorando procesos donde se requiere avanzar y retroceder rápidamente.

Características

  • Nodos enlazados en ambos sentidos
  • Recorridos flexibles
  • Estructuras dinámicas
  • Conexión circular opcional
  • Mayor uso de memoria

Representación

Una lista doble utiliza dos referencias por nodo: anterior y siguiente. 


NULL ← [10] ⇄ [20] ⇄ [30] → NULL

En listas circulares, el último nodo apunta nuevamente al primero. 


[10] → [20] → [30]
  ↑_______________|

Casos de Uso

  • Historiales de navegación web
  • Reproductores multimedia
  • Sistemas operativos
  • Gestión de procesos circulares
  • Juegos y simulaciones

Pantalla de Ejemplos

Paso 1

Definir la estructura del nodo con dos enlaces. 


struct Nodo{
   int dato;
   Nodo *siguiente;
   Nodo *anterior;
};
Paso 2

Crear dos nodos y conectarlos. 


nodo1->siguiente = nodo2;
nodo2->anterior = nodo1;
Paso 3

Ahora la lista puede recorrerse en ambas direcciones.

Paso 1

Crear varios nodos enlazados.

Paso 2

Conectar el último nodo con el primero. 


ultimo->siguiente = primero;
Paso 3

La estructura podrá recorrerse continuamente sin llegar a NULL.
