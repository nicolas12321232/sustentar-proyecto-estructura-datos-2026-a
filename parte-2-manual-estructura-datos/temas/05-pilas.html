Pilas — Stack

Pantalla de Documentación

Definición

Una pila es una estructura de datos lineal que almacena elementos siguiendo el principio LIFO (Last In, First Out).

Utilidad

Se utilizan para controlar procesos temporales, almacenar tareas y gestionar operaciones recursivas.

Características

  • Estructura lineal
  • Acceso limitado
  • Inserción y eliminación en el tope
  • Funcionamiento LIFO
  • Uso dinámico o estático

Representación

Los elementos se agregan y eliminan únicamente desde el tope. 


| 30 | ← Tope
| 20 |
| 10 |
-------

El último elemento agregado será el primero en salir.

Casos de Uso

  • Deshacer acciones en programas
  • Llamadas a funciones
  • Recursividad
  • Validación de expresiones
  • Navegadores web

Pantalla de Ejemplos

Paso 1

Crear una pila vacía. 


stack pila;
Paso 2

Insertar elementos utilizando Push(). 


pila.push(10);
pila.push(20);
pila.push(30);
Paso 3

El valor 30 quedará en el tope de la pila.

Paso 1

Consultar el elemento superior. 


pila.top();
Paso 2

Eliminar el elemento del tope. 


pila.pop();
Paso 3

El siguiente elemento pasará a ocupar el tope.
